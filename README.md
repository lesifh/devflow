# DevFlow

一个面向软件团队的敏捷项目管理系统。

支持项目管理、迭代规划（Sprint）、工作项跟踪（需求/任务/缺陷）和看板视图。

## 技术栈

- 后端：FastAPI + SQLModel + SQLite
- 前端：React + TypeScript + Vite
- 认证：JWT

## 核心概念

- **项目（Project）**：一个软件项目
- **迭代（Sprint）**：项目下的开发周期
- **工作项（WorkItem）**：需求 / 任务 / 缺陷
- **看板（Board）**：按状态展示工作项
